# Operational Loop

This document captures the operating loop demonstrated by the simulator.

1. Start or continue a scenario.
2. Review storeroom inventory and fill gaps.
3. Review vendor and catalog options.
4. Draft and review current orders.
5. Receive or stage inventory for route use.
6. Load machines by slot and depth.
7. Review reports for the current operational state.

The value of the model is that these steps are connected. Inventory decisions affect orders, orders affect loadout options, and the resulting state rolls up into reporting surfaces.
