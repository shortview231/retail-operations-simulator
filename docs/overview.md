# Overview

`retail-operations-simulator` is a standalone portfolio case study in operations modeling, persistent state, and decision-support workflow design.

## What the repository demonstrates

- a vending-first operational model
- connected inventory, vendor, ordering, machine, and reporting workflows
- SQLite-backed persistent scenario state
- public-safe example data and demonstration surfaces
- architecture and verification notes that make the project inspectable

## Why the project matters

The project is designed to show more than a dashboard mockup. Inventory, procurement, machine planning, and reporting are modeled as connected parts of an operating process.

That makes the repository useful as evidence of translating a real-world workflow into data structures, state transitions, and reviewable decision surfaces.

## Demonstration pack

The repository includes:

- architecture and workflow notes under `docs/`
- sanitized sample state under `examples/`
- eight demonstration surfaces under `screenshots/`
- verification notes describing what each artifact is intended to show

## Skills represented

- operational process analysis
- relational and state modeling
- SQLite-backed persistence
- inventory and procurement logic
- workflow decomposition
- reporting design
- technical documentation

## Public-data boundary

Only portfolio-safe documentation and examples belong in this repository. Real customer records, credentials, personal identifiers, private production configuration, and unrelated private systems are outside its scope.
